- `SchedulingEvidenceBuilder` requires an active, verified, crop/variety/region matching profile with at least one nondeleted stage. If Member 3 supplied `requirementSource.cropReferenceProfileId`, Member 4 must use that exact profile. `CropResourceRequirementService` requires a resource rule but does not require stages. A valid rules only profile can therefore complete Member 3 and leave Member 4 blocked. The reference-profile form and validator also allow rules without stages. This is an evidence compatibility gap, not permission to approve an incomplete candidate.

- The `FinalCultivationGuideAgent` is called only after a successful human approval. It writes a revision scoped guide step from persisted approved work and upstream summaries. The farmer approved-plan API includes `finalGuide` only when that step completed; Flutter displays it only when present. The guide cannot appear on a `MissingDependency` workflow.
